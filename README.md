# Awesome VR Ports [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

A curated list of open-source games and engines ported to virtual reality.

The list below is kept in sync with a GitHub star list by a
[scheduled workflow](.github/workflows/sync.yml). To suggest a port, open an issue.
